【第三章】GitHub Pages 30 秒免費全球上線指引（取得作品公開網址）
期中期末繳交必備

全學期 100% 零花費！無須購買任何主機或網域，依照 4 個步驟即可取得你的專屬網址：

步驟 1
建立 Public 儲存庫

登入 GitHub 點右上角 + ➔ New repository，輸入專案名稱（如 vnu-project），設為 Public，點擊 Create。

步驟 2
上傳 index.html

點擊 Add file ➔ Upload files，將生成的網頁檔案命名為 index.html（⚠️ 全部小寫）並拖曳上傳，點擊 Commit。

步驟 3
開啟 Pages 功能

進入儲存庫 Settings ➔ 左側點 Pages ➔ Branch 選擇 main、資料夾選擇 / (root) ➔ 點擊 Save。

步驟 4
複製網址並繳交

等待 30~60 秒，頁面會產生專屬網址：https://帳號.github.io/專案名/，複製貼至本平台【學生作品展示中心】！
